## Not adopted

- **Microphone (`DM_MIC`, `DM_MIC_DEVICE`, `DM_MIC_GAIN`).** Off by default upstream; the packed Mac app asks macOS for consent itself. Offering it would be a new Game options capability with no demonstrated need yet.
- **Polish and Thai as game languages.** Arcane's **Game language** list is a chosen subset of what the engine accepts (Dutch, Russian, Traditional Chinese and the regional variants are not listed either). Adding languages is a product choice, not a missing wire.
- **`DM_NVN_UPLOAD_IDLE_MS`, `DM_NVN_UPLOAD_SRC_MB`, `DM_WINDOWLESS_ROLE`, `DM_DETCLOCK`.** Engine tuning and test switches.

## Arcane changes with this pin

- `AppViewModel.pinnedEngineCommit` is `e59c910a`. The cached upstream status is keyed on the pin, so it is read again.
- A player whose **Newest engine** choice is a commit this pin includes loses that choice at the next environment check (`NewestEngine.keeps`), and the untested override goes back off if the choice turned it on. Setup then shows the engine card as **Update ready**; Update moves the checkout to the pin.
- The Game options note **Internal resolution** no longer says native 1440p/4K is unavailable in this engine pin. It appears only for builds without a render scale stub, and with this pin some builds go above 1.0 (Hades II up to 3.0). It now says the build has no 3D render scale.
