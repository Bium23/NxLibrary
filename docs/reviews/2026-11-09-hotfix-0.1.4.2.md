## Final scope

- Session card: `<1m` and a fixed leading-aligned content width prevent short-session text overflow (earlier commit 608e7e1).
- Xcode requirements: parse the installed `Xcode 27.2` prefix correctly and avoid asking to upgrade an already-current toolchain.
- Disk errors: recognize pack_app's space check including its 1 GiB reserve; NUP/extracted sources do not receive the missing-keys fallback. Retain @eduardomozart's PR #13 fix/tests and extend the engine-message check to dm/mac.
- Long builds: elapsed time updates, hour formatting and percentages from @eduardomozart's PR #11. Pipeline tracking was replaced with a current-log reader: actual batch sizes, confirmed ready (compiled/reused), no inference from temporary/cache files, joined parallel-worker records, generation guards after cancellation/next stage, and an estimate limited to pipelines.
- Icon source and location are independent. Automatic preserves Only here / Use on the Mac and original-image provenance. Icon location is reachable through the existing keyboard/controller grid. Missing replacements remove the prior personal app icon and restore the original/generic icon. The picker and finished build log explain a missing image; Play remains available.
- Play waits safely for icon signing; Cancel or a replaced notice revokes the pending launch. Rapid changes finish one signature then reread the latest source/location.
- Title DB fallback validates/caches square images separately from personal picks. Switch Icon Showdown remains blocked by its current /images/ opt-out; no claim that issue #12's full automatic Switch 2 fallback is solved. LaunchBox remains a manual artwork source.
- A regression check preserves a saved 120 FPS selection through unrelated edits and launch migration. Six upstream profiles currently offer 120; Ocarina offers 30/60. Metadata support is not a physical 120 FPS gameplay certification.
- README highlights and mod-store screenshot/documentation (earlier commit 2fcb114).
- Pin latest upstream 79741184 on the maintainer's explicit instruction. See the [71-commit review](../upstream-upgrades/2026-11-09-bd979ced-79741184-review.md): same Metal 32023.922, no new Python packages, changed shader chain, backend/runtime improvements and existing metadata-driven controls. Installed games retain their embedded engine until rebuilt.
