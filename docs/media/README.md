# Immagini e video del README

Il README apre con l'icona di Arcane, il nome e la descrizione. Spotlight introduce la libreria. Le altre immagini accompagnano le funzioni della guida.

Le copie WebP sono larghe 1920 pixel, mantengono le proporzioni delle catture e usano il profilo colore sRGB. Le didascalie e i testi alternativi sono in inglese. [settings.webp](settings.webp) documenta l'interfaccia di NX Library precedente alla riorganizzazione di Settings.

Le copertine, i loghi e i wallpaper visibili nelle catture restano soggetti ai diritti e ai termini dei rispettivi proprietari.

## Aggiornare le immagini

Conservare le catture complete con lo stato originale dell'interfaccia. Aggiungere una copia WebP con didascalia e testo alternativo. Controllare che percorsi privati, chiavi e notifiche personali restino fuori dalle catture. Il commento `NX-SCREENSHOTS` delimita l'immagine d'apertura. Aggiornare il [catalogo dei file](../file-map.md) se cambia l'inventario.

## Video subito dopo la presentazione

Il blocco `NX-DEMO` accoglie un allegato GitHub subito dopo la presentazione. Preferire un MP4 con H.264 e verificare la riproduzione nel README pubblico. Segnalare nel video eventuali tempi di compilazione abbreviati.

Se il lettore non appare nel README, usare un fermo immagine che apre il video. [Allegati GitHub](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)
