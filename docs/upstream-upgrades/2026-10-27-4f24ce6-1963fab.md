## UI/backend decisions

- **UI:** read `launcher.json`; hide render scale when the build has no stub; add a Display card with the runtime fullscreen switch; clarify that output resolution is the window/display and render scale is internal.
- **Backend:** pass settings in the launch environment (environment wins over `env.txt`), keep writing `env.txt` for Finder launches.
- **Not adopted:** native 1440p/4K selector. Upstream still has no render scale above 100%; issues #76/#159/#374 and PR #345 are open/not merged. The app does not invent a control the engine cannot honor.
- **Not adopted:** automatic following of `main`; the pin is explicit.
