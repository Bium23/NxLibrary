## Adoption and rollback

Adoption waits for the maintainer's confirmation. The upgrade does not rebuild installed games. Rollback uses the previous pin and engine checkout; a game rebuilt with this engine has its cache in `cas.db`, which the previous engine does not read, so going back costs that game a full shader rebuild.
