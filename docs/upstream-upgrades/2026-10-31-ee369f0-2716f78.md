# 2026-10-31 — nxnative ee369f0 → 2716f78

## Why

Host cheats: nxnative `ef9f9bb` (PR #406) runs Atmosphère cheat codes on the host, with a Mac Cheats panel in the game window. NX Library's Cheats panel (project 3, [the cheats spec](../superpowers/specs/2026-10-31-cheats-design.md)) installs and switches the same files before Play, so the pin must contain `ef9f9bb`. `2716f78` was `origin/main` when the review started; 90 commits after `ee369f0`. The 7 commits on `origin/main` after `2716f78` are not part of this pin.

## Toolchain: an explicit, recorded override

`dm/gfx/tools/dmsh_chain.lock` still certifies `Apple metal version 32023.921 (metalfe-32023.921.6)`, unchanged in this delta. This Mac runs Xcode 27.2, whose own Metal toolchain is `32023.922` (`metalfe-32023.922.4`, asset 27B47). The certified `32023.921` toolchain (asset 27A266a) was downloaded and mounted, but Xcode 27.2 never selects it (`TOOLCHAINS` is ignored), so the certified compiler cannot be reached without Xcode 27.1 side by side.

**By the user's choice**, verification used the uncertified `32023.922` through **Untested toolchain override** (`--allow-other-metal`; builds recorded `toolchainVerified=false`). The same is true of the previous pin on this Mac. **Rebuild the game once upstream certifies `32023.922`** (or with Xcode 27.1), and add that compiler to `ToolchainRequirements.current.metalAssets` then (AGENTS.md step 6).
