## Update and rollback

Release 0.1.0 is the update-test baseline. A later numbered release keeps the bundle ID, library format, preference paths and runtime lock. Updating the app changes its engine requirement; Setup prepares the required engine separately. Existing game apps remain playable and are not replaced by updating the launcher.

Failed app replacement retains the previous app. A manual rollback uses the earlier release; its engine pin can be restored through Setup when rebuilding is needed. The update does not migrate saves, rewrite source selections or alter key storage.
